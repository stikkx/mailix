Mailix pacman repository

Packages for Mailix, built by its release workflow from the official release tarball.

[mailix]
SigLevel = Optional TrustAll
Server = https://stikkx.github.io/mailix/x86_64

Add that to /etc/pacman.conf (or include it from /etc/pacman.d/mailix.conf), then sudo pacman -Sy mailix.

Later updates arrive with the rest of the system: on Omarchy that is omarchy update (Omarchy refuses a direct sudo pacman -Syu), on plain Arch sudo pacman -Syu.

x86_64/
